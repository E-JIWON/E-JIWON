# 오늘도 비둘기한테 졌다 — 게임 프로젝트

세로 9:16 모바일 웹게임. Vite 8 + TypeScript 6(strict) + three.js 0.186.1.

## 실행
```bash
npm install          # .npmrc 의 legacy-peer-deps 사용
npm run dev          # 개발 서버(같은 와이파이의 폰에서 접속 가능: --host)
npm run build        # 타입체크 + 정적 빌드(dist/)
node tests/e2e.mjs   # 빌드 후 터치 e2e 11개(+성능 기록), 결과 tests/out/
node tests/sfx-check.mjs  # 효과음 52개 검사(OfflineAudioContext)
```

## 구조
`src/config.ts`(튜닝 수치 전부) · `src/content`(비둘기·참사 정의) · `src/render`(재질·텍스처·모델·거리·렌더러) ·
`src/game`(상태·시뮬레이션·행동·이벤트 버스) · `src/input`(포인터 상태 머신) · `src/ai`(자동 데모) · `src/ui`(HUD·효과 글자·컷신·오버레이) ·
`src/audio/sfx.ts`(Web Audio 합성 효과음·배경음). 계약과 필수 동작은 `CONTRACT.md`.

## 단계
1. **기반(완료)**: 프로토타입을 정식 프로젝트로 이식, 효과음·배경음 합성, e2e 테스트.
2. **손맛·비주얼**: 30초 구간(골목, 구구·닭둘기, 참사 2종)을 출시 수준으로. 애니메이션, 외곽선 후처리, 파티클, 컷신 연출.
3. **아트 파이프라인**: glTF 모델 교체 구조, 아트 방향 확정(직접·외주·에셋).
4. **콘텐츠**: 비둘기 4종, 참사 9+1, 60초 3막, 도감, 결과 카드·공유.
5. **실기기·출시**: 폰 실측 튜닝, 성능 예산, OG·메신저 공유, 배포.

## 알려진 것
- 번들 608KB(three.js). 2단계 이후 필요한 모듈만 가져오도록 정리 예정.
- 취소 시 원위치 착지는 게임 시간 약 0.65초(원본과 같음, 계약의 240ms보다 김) — 2단계 손맛 작업에서 조정.
- 입력 판정은 실제 시간, 정 게이지·프리즈·컷신은 게임 시간(프레임당 최대 0.05초) 기준. 아주 느린 기기에서는 게임이 느리게 흐른다.
- 효과음 음량은 측정값 기준이며 실제 폰 스피커 청취 확인 전.
